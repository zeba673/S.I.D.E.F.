# S.I.D.E.F.

MVP demostrativo del Sistema Inteligente de Detección de Evasión Fiscal.

## Desarrollo

```bash
pnpm install
pnpm dev
```

La aplicación funciona inicialmente con datos sintéticos locales. Para preparar Supabase, creá un proyecto, aplicá la migración de `supabase/migrations/` y completá `.env.local` usando `.env.example`.

## Verificación

```bash
pnpm test
pnpm build
```

Las alertas son señales para revisión humana. Los datos demostrativos no representan personas ni organizaciones reales.
